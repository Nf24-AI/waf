# thmanyah font licence — read before any public deploy

The WOFF2 files in `assets/fonts/` are the thmanyah typeface,
© 2026 thmanyah Publishing and Distribution.

The licence permits commercial use and embedding **only as part of a compiled,
packaged or obfuscated product**, and **prohibits hosting the font files in a
way that lets third parties download them**.

A Vite build emits these files as plain static assets under `/assets/`, so any
visitor can download them directly. That is the prohibited case.

- Local development: fine.
- A private repository: fine.
- **A public origin or a public repository: not cleared.** Confirm the delivery
  method with thmanyah at `ask@thmanyah.com` first.
